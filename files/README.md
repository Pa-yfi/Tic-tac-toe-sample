# 🎲 ربات بازی دوز — نسخه‌ی کامل

## 🚀 اجرا
```bash
pip install -r requirements.txt
# توکن را در .env بگذار
python bot.py
```
## ⚠️ تنظیمات اجباری در BotFather
1. `/setinline` → یک placeholder بده (مثلاً «بازی دوز…») — بدون این، ربات اصلاً اینلاین کار نمی‌کند.
2. `/setinlinefeedback` → **100%** — بدون این، آپدیت `ChosenInlineResult` نمی‌آید و ربات نمی‌فهمد پیام کجا فرستاده شده.
   (کد fallback هم دارد و با اولین کلیک `inline_message_id` را برمی‌دارد، ولی با feedback روشن تجربه بهتر است.)
3. برای بازی در گروه: `/setjoingroups` روشن باشد (لازم نیست ربات عضو گروه شود، اینلاین کافی است).
4. برای دریافت افکت 🎯 برنده، کاربر باید یک‌بار ربات را `/start` کرده باشد.

برای اجرای دائمی روی سرور: `WEBHOOK_URL` را در `.env` ست کن (وگرنه polling استفاده می‌شود).

## 📁 ساختار
| فایل | کار |
|---|---|
| `bot.py` | هندلرها، لابی، تایمر، انیمیشن، مرور بازی |
| `game.py` | منطق بازی، حالت‌ها، هوش مصنوعی (minimax + alpha-beta) |
| `db.py` | SQLite: بازی‌ها، Elo، آمار، دستاوردها، جدول امتیازات |
| `i18n.py` | متن‌های فارسی/انگلیسی + دستاوردها |

## ✅ ۲۰ قابلیت
1. بازی با ربات (آسون/متوسط/سخت — minimax + alpha-beta)
2. تایمر نوبت (۳۰/۶۰ ثانیه)
3. حالت گراویتی 🪂 (اتصال‌چهار)
4. حالت معکوس (Misère) 🙃
5. حالت سه‌مهره‌ای ♻️
6. Undo با تأیید حریف ↩️
7. بازی ۳ و ۴ نفره (روی ۵×۵ و ۶×۶)
8. جدول امتیازات هر چت 🏅
9. سیستم Elo با نمایش `+12 / -8` 📈
10. دستاوردها 🎖️ (۸ مورد)
11. سری Best-of-3/5 🏆
12. `/stats` — برد/باخت، درصد، خانه‌ی محبوب، رکورد استریک
13. ست‌های ایموجی 🎨 (کلاسیک/حیوانات/عناصر/فضا)
14. انیمیشن برد — خانه‌های برنده یکی‌یکی 🟥 می‌شوند
15. افکت 🎯 برای برنده
16. مرور بازی 📜 (پخش حرکت‌به‌حرکت)
17. پیشنهاد مساوی 🤝
18. چندزبانه 🌐 (`/lang`)
19. دیتابیس SQLite به‌جای JSON
20. Webhook + لاگ متریک 📊
